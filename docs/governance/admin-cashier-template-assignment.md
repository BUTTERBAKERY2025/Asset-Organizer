# مسار إسناد قالب الكاشير للأدمن

## سبب الإصلاح
قائمة تجربة الأدمن كانت تستخدم كتالوج مدير التشغيل وسقف تفويضه؛ لذلك اختفى قالب كاشير معتمد يحتوي صلاحيات عرض إضافية. الاعتماد لم يفشل، لكن سبب الاستبعاد لم يكن ظاهرًا.

## الحدود الجديدة
- قائمة مستقلة للأدمن تعرض جميع الإصدارات الأحدث المعتمدة دون تصفية بسقف العمليات. ظهور الإصدار ليس إذنًا بإسناده.
- المقارنة والتطبيق للأدمن يدعمان إجراءات التشغيل السابقة، وإجراءات العرض والقائمة والتفاصيل، وإجراءات العرض فقط لوحدات الصفحة الرئيسية ولوحة التحكم والكاشير وأدائه والحوافز والتحديات والعمولات ومكافأة الفرع ومحفظة النقاط.
- لا منح إدارة مستخدمين أو رواتب أو إعدادات نقاط أو اعتماد صرف حوافز بهذا المسار. الصلاحيات الأخرى تظهر برسالة منع تحدد الوحدة والإجراء، ولا تُحذف من القالب.
- لا يُغيَّر كتالوج مدير التشغيل أو سقفه أو مسارات كتابته. الحساب الذي توسع خارج سقفه يبقى محميًا منه.
- يبقى الحساب قائمًا ونشطًا وذا ربط واحد وفرع مطابق، ولا يُتجاوز منع الحسابات الإدارية والإسنادات القديمة والاستثناءات غير الآمنة.
- الصلاحيات المختارة تُحفظ كاملة، مع بقاء الإضافات والرفض والتدقيق وإبطال الجلسات وفحص المقارنة داخل المعاملة نفسها.
- «فرع معين» ليس ضمانًا بأن كل مسار قديم يقيّد بياناته بهذا الفرع. تعرض الشاشة التحذير ومحتوى القالب منفصلًا عن القرار الفعلي؛ لم تتغير ضوابط الموارد أو الوظائف في تلك المسارات.

## التشغيل
لا ترحيل بيانات جديد، ولا تعديل للقالب الحي أو الحسابات. يحتاج الإصلاح نشر الشيفرة على Render عبر Git، ثم إعادة تحميل الصفحة. لا يلزم حذف صلاحيات الإصدار المعتمد أو إعادة اعتماده لمجرد إصلاح الكتالوج.

## التحقق
اختبارات مركزّة للسياسة والمسارات: 125 ناجحًا. اختبارات الواجهة: 118 ناجحًا. اختبار PostgreSQL مؤقت وخادم حقيقي: 184 تحققًا يغطي الكتالوجين المختلفين، سبب المنع، منع الكتابة غير المؤهلة، حفظ جميع الصلاحيات المختارة، بقاء الرفض، إعادة المقارنة بعد التطبيق وقراءة صلاحيات الحساب بعد تسجيل دخول جديد. بناء الإنتاج ناجح.

اختبار متصفح على البيئة المؤقتة نجح في إظهار القالب الموسع، منع قالب إدارة المستخدمين مع سببه، مراجعة المحتوى والحدود والرفض المستقل، ثم تأكيد وإسناد حساب واحد وإعادة قراءة المقارنة. لم يُطبَّق أي قالب على حساب حي. ظهور الحساب بعدها كمحمي في قائمة العمليات مقصود عند تجاوزه سقف مدير التشغيل؛ تبقى تجربة الأدمن متاحة.
