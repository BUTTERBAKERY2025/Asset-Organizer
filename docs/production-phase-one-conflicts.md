# سجل تعارضات المرحلة الأولى — أدلة شيفرة لا حالة تشغيل

الحالة **مراجعة شيفرة مكتملة فقط (CODE ONLY)، ليست موافقة تشغيل**. الشدة: حاجز إطلاق / عالٍ / متوسط؛ تصنيف الدليل: `confirmed-code` (سلوك مثبت في المصدر)، `needs-live-verification` (لا إثبات في البيئة)، `decision-needed` (سياسة غير محسومة). قد يتداخل تصنيفان؛ لا تعني ملاحظة الشيفرة أن المسار منشور أو أن قاعدة التشغيل مُرحّلة. المالك المقترح مسؤول قرار، لا حساباً مُنح صلاحية. راجع [القواعد](production-phase-one-rules.md) و[الفهرس](production-operating-baseline.md).
