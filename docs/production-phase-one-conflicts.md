# سجل تعارضات المرحلة الأولى — أدلة شيفرة لا حالة تشغيل

الحالة **مراجعة شيفرة فقط (CODE ONLY)؛ P1-01 منفذ في التطوير وينتظر ترحيل الإنتاج والنشر والتحقق الحي، لا موافقة تشغيل شاملة ولا اكتمال المرحلة الأولى**. سُجل قرارا المستخدم بتاريخ 2026-09-26. الشدة: حاجز إطلاق / عالٍ / متوسط؛ تصنيف الدليل: `confirmed-code` (سلوك مثبت في المصدر)، `needs-live-verification` (لا إثبات في البيئة)، `decision-needed` (سياسة غير محسومة)، `decision-resolved / implementation-open` (قرار محسوم وتنفيذه مفتوح)، `implemented-development` (منفذ في شيفرة التطوير لا منشور بالضرورة). قد يتداخل تصنيفان؛ لا تعني ملاحظة الشيفرة أن المسار منشور أو أن قاعدة التشغيل مُرحّلة. المالك المقترح مسؤول قرار، لا حساباً مُنح صلاحية. راجع [القواعد](production-phase-one-rules.md) و[الفهرس](production-operating-baseline.md) و[إصدار الاستثناء](recipe-exception-release.md).
