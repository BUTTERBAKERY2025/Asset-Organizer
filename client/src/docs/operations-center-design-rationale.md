# Operations center: daily decisions before detail

The center is a compact, icon-led daily workspace. The opening list prioritizes records with actual elapsed deadlines, then personal assignments, then other follow-up records. An elapsed deadline is not automatically a safety emergency; assignment alone is not approval authority.

Domain drawers and record sheets replace long, permanently expanded source lists. Counts describe the loaded queue page, not a guaranteed global total. Empty task groups do not create empty tabs; authorized domain tools remain reachable when there are no tasks. Record selection is re-resolved against current scoped data.

Monthly details combine independently authorized payroll snapshots/payment records, recorded expenses, daily closing evidence, and journal sales. A recorded expense is not proof of cash payment, a payroll snapshot is not the amount disbursed, and no combined financial month-close state is invented. Links retain branch and month.

Charts visualize actual comparable evidence and disclose incomplete sources. AI analysis is requested explicitly, uses server-selected authorized evidence without names or free-form record text, and returns suggestions linked to source records rather than executing decisions. Notification read/dismiss remains separate from completing operational work.
