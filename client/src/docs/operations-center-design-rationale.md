# Operations center: overview, then directed drilldown

The prior three-pane UI repeated 14 branches × 14 source cards (196 rows), then kept a detail inspector open by default. The source list looked like an inbox even when it represented domain coverage, not actions. The new default is a compact scope overview: the **loaded queue page** and confirmed personal assignments, non-ready card sources, four source-ordered records, and a five-branch preview. No inferred severity, branch health, or summed heterogeneous source measures. The other branches, all records, domains, and dated evidence have dedicated views.

**Navigation:** overview → follow-up record; overview → branch → sources; sources → domain → branch source; each detail opens only on a click. Domain grouping reduces 196 source rows to 14 collapsed domain entries, while retaining all 196 exact branch-source links on expansion. The branch filter is searchable and contextual rather than a permanent rail. Selection is keyed by both `branchId` and `card.id`; a vanished selection closes rather than silently showing another branch. The selected queue record also disappears when its filtered page changes.

**Evidence / limits:** Grafana's [dashboard guidance](https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/best-practices/) recommends hierarchical directed drilldowns and comparing like with like; this motivated grouping without summing metric values. [NNGroup progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) was successfully fetched by the main agent: show a few important options initially and offer specialized options on request. [Carbon filtering guidance](https://v10.carbondesignsystem.com/patterns/filtering) was located in search: hidden filters should retain a visible applied-state indicator. These are selected references, not an exhaustive survey or a copied product design. The UI labels queue counts as a loaded page and states unavailable/truncated coverage separately; zero is never interpreted as healthy. No charts or invented KPI scores.
